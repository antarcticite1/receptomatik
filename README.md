# Что приготовить?

Android-приложение: отмечаете продукты, которые есть дома, и видите, что из них можно приготовить.

- 129 рецептов 18 кухонь, фильтры «без мяса», «без рыбы», «без лактозы»
- пошаговый режим: таймер, который звонит даже при свёрнутом приложении, и чтение шагов вслух
- меню на неделю и список покупок, где одинаковые продукты суммируются
- «Удиви меня», избранное, «Поделиться», таблица «сколько граммов в ложке»
- работает без интернета

Разрешения: интернет (ссылки и фото при сборке), уведомления и точный будильник (таймер), вибрация.

## Где что лежит

| Путь | Что внутри |
|---|---|
| `app/src/main/assets/index.html` | разметка экрана |
| `app/src/main/assets/js/app.js` | логика приложения |
| `app/src/main/assets/js/recipes.js` | продукты и рецепты |
| `app/src/main/assets/js/measures.js` | таблица мер |
| `app/src/main/assets/js/art.js` | иллюстрации и значки |
| `app/src/main/assets/css/app.css` | оформление |
| `app/src/main/java/.../MainActivity.java` | Android-оболочка: один экран с WebView |
| `tools/prepare-assets.mjs` | при сборке скачивает фото блюд с Викисклада вместе с автором и лицензией, а также шрифты Google Fonts |
| `.github/workflows/build.yml` | сборка APK на GitHub Actions |

## Фото к шагам рецепта

Положите картинку в `app/src/main/assets/steps/` с именем `<id рецепта>-<номер шага>.jpg`, например `borsch-1.jpg`, `borsch-2.jpg`. Подойдут `.jpg`, `.png` и `.webp`. Id рецепта — поле `id` в `js/recipes.js`. При сборке фото появятся в рецепте и в пошаговом режиме вместо рисунка; у шагов без фото останется рисунок.

## Как проверить, что APK собран из этого кода

Каждый APK в разделе Releases собирается GitHub Actions из этого репозитория. В описании релиза есть ссылка на журнал сборки и номер коммита, а рядом с файлом лежит его SHA-256.

Ключ подписи хранится в секретах репозитория (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`) и в код не попадает.

Фотографии блюд — с Викисклада, только под свободными лицензиями. Автор и лицензия каждого фото указаны в рецепте со ссылками на страницу файла и текст лицензии. Если при сборке Википедия недоступна, используется фото из репозитория со ссылкой на статью-источник.
